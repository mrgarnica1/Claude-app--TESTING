# Claude-app--TESTING

## Europe 2026 Trip Companion

An installable PWA trip itinerary for an 18-day Europe trip (Barcelona, Rome, a Greek Isles cruise, Paris, and a NYC layover) — day-by-day timeline, flights, stays, and bookings, all working fully offline.

- `index.html` — the app
- `manifest.json`, `sw.js` — PWA install support + offline caching
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — app icons
- `SETUP.md` — instructions for hosting, installing on a phone, and optional push notification alerts via OneSignal

Deployed automatically to GitHub Pages on every push to `main` (see `.github/workflows/deploy.yml`).
